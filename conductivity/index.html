How λ and c relate

A truly power-law pore distribution, ΘE ∝ rλ, gives K ∝ rλ+2 and so c = 1 + 2/λ exactly. This distribution is only a power law in its small pores, where r² e−r/r̄ ≈ r² gives λ → 3 and c → 5/3, which satisfies the relation. The large pores bend the curve, so one straight line cannot fit it, and both exponents depend on the fit range.

Pores with r > r̄ × the cutoff are removed, not redrawn. With a unit gradient each full pore carries Q = (π/8)(ρg/μ) r⁴, so K = (ρg / 8μ) Σ r⁴ / R² over the pores with r ≤ r* = 2σ/(ρg|h|). Sample height cancels. No tortuosity correction, so b = 0.

The handout writes the leading factor as 1/(ρg). Since ΔP + ρgΔz = ρg ΔH, it has to be ρg for Q to come out in m³/s, and that is what is used here.
